## 구성

**01. 법령 · 규제**
- 재생에너지법 전면 개편 (제명 변경, 신·재생 분리)
- 이격거리 규제의 국가 기준화 (태양광 주거 200m / 도로 100m 상한)
- RPS 폐지 및 장기 경매제 전환 (2027.1 목표, REC 현물시장 2030 폐지)
- 영농형 태양광법 (2026.12.17 시행) / 개정 농지법 (2026.8.28 시행)
- 계통 규제 (계통관리변전소, 출력제어, 배전망 ESS 700MW)
- 분산에너지 특별법, 폐모듈 EPR, KS인증·시공기준, 한국판 IRA, 11차 전기본

**02. 설치업체 동향**
- 국내 설치량 4.0GW(2026E) / 글로벌 20년 만의 첫 역성장
- 제조사: 한화솔루션, OCI홀딩스, HD현대에너지솔루션, 신성이엔지
- 개발·EPC·운영사: SK이터닉스, 브라이트에너지파트너스, 대명에너지 등
- 수익성 지표 변화(SMP·REC·고정가격 상한), 분쟁·부실시공 이슈
- 경쟁축 이동: 시공단가 → 금융구조화·인허가 관리·O&M 통합

**03. 신기술 · 신제품**
- 셀 기술 3파전: TOPCon(65%+) / HJT / BC
- 페로브스카이트-실리콘 탠덤 (28.7% 셀, 진천 파일럿, 실증 2026~2029)
- 응용: 영농형, 수상, BIPV, 데이터센터 지붕형, 특수입지
- 그리드포밍 인버터(2027.12 적용), 배전망 ESS, VPP
- AI 고장진단(정확도 95%+), 디지털트윈 예측정비(O&M 비용 -30%)
- 폐모듈 재활용(최대 98%), 리파워링

## 자동 갱신

매일 08:00(KST) 「태양광정보」 루틴이 3개 축을 재조사합니다. 실질적 변동이 있는 날에만
동일한 아티팩트 URL과 `reports/` 하위 파일을 갱신하며, 변동이 없으면 아무것도 커밋하지
않습니다. 갱신 시 변경된 제도·수치는 리포트 상단 메타 정보의 기준일로 확인할 수 있습니다.

## 카카오워크 알림

루틴은 **매일** 실행 결과를 카카오워크로 보냅니다. 갱신한 날은 3개 축 요약과 리포트
링크를, 변동이 없는 날은 확인 결과 한 줄을 전송합니다.

| 파일 | 용도 |
|---|---|
| [`scripts/kakaowork_send.py`](scripts/kakaowork_send.py) | 카카오워크 봇 발송 스크립트 (표준 라이브러리만 사용) |
| [`docs/kakaowork-setup.md`](docs/kakaowork-setup.md) | 봇 앱 키 발급 · 환경변수 · 도메인 허용 설정 절차 |

발송에는 `KAKAOWORK_APP_KEY` 와 `KAKAOWORK_EMAIL`(또는 `KAKAOWORK_CONVERSATION_ID`)
환경변수, 그리고 `api.kakaowork.com` 이그레스 허용이 필요합니다. 자세한 절차는 위 설정
문서를 참고하세요.
